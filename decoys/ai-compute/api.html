Authentication

All API requests require a Bearer token in the Authorization header. Generate API keys from your dashboard.

GET/v1/clusters

List all GPU clusters in your organization.

POST/v1/clusters

Launch a new GPU cluster.

Example request:
curl https://api.nexuscompute.cloud/v1/clusters \\ -H "Authorization: Bearer nullpot_test_key_01" \\ -H "Content-Type: application/json"

API Keys

Create, rotate, and revoke API keys. Keys are scoped to your organization.

nullpot_test_key_02 nullpot_test_key_03 nullpot_test_key_15

Webhook Endpoints

Receive cluster events via webhook. Register your callback URL in the dashboard.

POST https://api.nexuscompute.cloud/v1/webhooks Body: {"url": "https://api-webhook-7e9c2b4d6f8a0c1e3g5i7k9m0o.yourdomain.com/nexus", "events": ["cluster.ready", "cluster.error"]}
